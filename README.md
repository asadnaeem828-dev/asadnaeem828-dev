## 💎 Verified Data Standards

Every dataset generated by these actors adheres to strict data hygiene rules:
- **Zero Empty Fields**: 100% of rows contain verified company names, websites, and geographic details.
- **RFC 5322 Email Validation**: Direct executive and corporate emails verified against domain MX records.
- **E.164 Phone Formatting**: National dial codes included for automatic CRM integration.
- **Accreditation Numbering**: Official association registration numbers included for audit compliance.

## 🛠️ Quick Integration (Python API)

You can programmatically extract records from any of these actors using the official `apify-client`:

```python
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_API_TOKEN")

# Example: Run HARDI HVAC Wholesale Distributors Scraper
run = client.actor("automation_studio/hardi-hvac-distributors-scraper").call(
    run_input={"maxResults": 1000, "requireEmail": True}
)

# Fetch dataset items directly into pandas or CRM
dataset_items = client.dataset(run["defaultDatasetId"]).list_items().items
print(f"Extracted {len(dataset_items)} verified distributor leads.")
```
